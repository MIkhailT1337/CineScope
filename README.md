# CineScope

## О проекте

CineScope — учебный многостраничный сайт-каталог фильмов.

Проект создан в рамках лабораторной работы №1
по дисциплине «Интернет-программирование».

## Используемые технологии

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Git

## Структура проекта

- public/index.html — главная страница
- public/catalog.html — каталог фильмов
- public/item.html — информация о фильме
- public/add.html — форма добавления фильма
- public/css/style.css — общие стили сайта

## Запуск

1. Открыть папку проекта в Visual Studio Code.
2. Открыть public/index.html с помощью Live Server.
3. Использовать меню для перехода между страницами.

## Ограничения

Проект использует статические HTML-страницы.
Поиск, фильтрация и сохранение новых фильмов пока не реализованы.
